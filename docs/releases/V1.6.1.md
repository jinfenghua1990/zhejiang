# V1.6.1 供应链界面收口版

发布日期：2026-09-08

## 版本定位

V1.6.1 不新增一套业务逻辑，重点是把 V1.6.0 已经落地的供应链能力收成一套稳定入口，减少历史页面、重复工作台和开发期导航对日常使用的干扰。

## 本次调整

### 供应链中心
- 供应链首页改为单一主流程：库存判断 → 补货计划 → 生产 / 采购 → 耗材备料 → 生产 / 在途 → 到货验收 → 吉客云入库。
- 顶部增加常用业务入口，一行直达补货、生产、耗材、采购、在途、到货、仓库和货品档案。
- 保留补货工作台作为供应链中心核心决策入口。
- 功能入口改成紧凑列表，不再使用过大的卡片堆叠。
- 明确采购工作台默认按下单时间组织，供应商使用独立视图。
- 页面版本信息从 V1.5 更新到 V1.6.1。

### 导航
- 左侧导航按“经营 / 供应链 / 财务 / 系统”重新分组。
- 去掉 P2 / P3 / P4 等开发阶段标记，避免把研发状态暴露给日常业务使用。
- 供应链相关页面全部保持展开显示，不增加折叠菜单。
- 侧边栏增加独立滚动，低分辨率页面不再挤压底部入口。

### 采购入口收口
- `/purchase/workbench` 继续作为唯一采购主工作台。
- 历史 `/purchase/workbench-v2` 停止独立维护并重定向到正式采购工作台。
- 原 `/purchase`、`/procurement-workbench`、`/procurement-board`、`/procurement-chain`、`/procurement-ledger` 继续保留兼容重定向，避免旧书签失效。

## 版本原则
- 不删除真实业务数据。
- 不改变 8000 单端口部署方式。
- 不新建第二套采购、生产或库存逻辑。
- 后续供应链新增能力只围绕 `/supply-chain` 与 `/purchase/workbench` 两个主入口扩展。
