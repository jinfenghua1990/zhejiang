# V1.6.0 本地首发版

发布日期：2026-09-08

## 版本定位

这是供应链中心第一版可用于本地真实业务验收的稳定候选版本，统一运行在现有 8000 端口。

## 主要功能

### 供应链中心
- 采购工作台统一承接 1688 / 淘宝 / 其他采购来源。
- 支持正品采购与耗材采购分类。
- 1688 订单备注中的吉客云入库单号可自动识别并匹配。
- 吉客云采购入库 Web 同步可用于采购入库跟踪。
- 生产、发货、在途、到货、吉客云真实入库形成闭环。

### 仓库
- 默认业务模型为工厂仓库 + B2C 仓库。
- 仓库可自行新增、改名、启停和调整用途。
- B2C 仓可绑定吉客云仓库 ID。
- 耗材收货按 warehouse_id 记录，兼容历史 factory / own 数据。

### 货品档案
- 正品、耗材、组合套装统一维护。
- 支持新建、编辑、导入和正品-耗材关联。
- 耗材可使用 HC- 前缀内部编码。

### 生产订单
- 新建、1688 导入和生产参数均在生产页面完成。
- 支持多 SKU、耗材需求、部分生产、部分发货、部分到货和吉客云入库关联。

### 财务月度销售汇总
- 销售汇总模板保存到数据库。
- 可自定义字段是否启用、字段名称和列顺序。
- 系统自动获取销售订单、SKU、商品、数量、金额、优惠、实付、退款等数据。
- 自动生成 Excel：销售汇总 + 销售明细两个 Sheet。
- 新账期将销售汇总作为固定财务资料之一。
- 可配置收件人、抄送、自动发送日期和小时。
- 到发送日期资料未齐时不误发，后续继续检查；发送成功后不重复发送。

## 稳定性修复
- 修复 Alembic multiple heads，数据库迁移已合并为单一 head。
- 修复财务发送接口收件人参数导致的 422 问题。
- 修复销售汇总完整性与金额格式相关测试。
- 保持 PostgreSQL 备份/恢复演练、孤儿引用审计、前端 TypeScript、production build 和 8000 单端口镜像校验。

## 部署前要求

真实业务库首次升级必须先执行：

```bash
make backup
make verify
make migrate
make rebuild
```

访问地址：

```text
http://localhost:8000
```

## 暂不阻塞本版本的后续项
- 1688 物流字段完全自动标准化需要真实已发货订单响应样本后再完善。
- 少量生产偏好参数后续可从浏览器配置进一步升级为数据库配置。
- 采购工作台超大页面后续可渐进拆分，不影响当前业务使用。

## 版本原则
- 业务配置尽量放在对应业务页面，不集中塞入系统设置。
- 仓库、货品、生产、财务均保持可修改、可扩展的自用系统交互方式。
- 不改变单端口 8000 的整体部署架构。
