# V1.6.2 供应链操作密度优化版

发布日期：2026-09-08

## 版本定位

V1.6.2 继续沿用 V1.6.1 已收口的供应链主入口，不新增第二套业务逻辑，重点减少弹窗、折叠和多步跳转，让生产与耗材执行更接近实际工作台使用方式。

## 本次调整

### 耗材流转
- “发工厂”不再连续弹出数量、物流、运单号输入框。
- 发料数量、物流公司、运单号改为表格行内直接填写。
- 工厂签收数量同样改为行内输入并确认。
- 发料与签收放在同一行，不再中断当前页面操作。
- 原 4 张大统计卡片改为顶部紧凑状态栏：生产单、已预占、发厂在途、工厂可用、生产缺料。
- 成功发料或签收后增加明确反馈信息，原有流转记录继续完整保留。

### 生产订单
- “生产配置”取消折叠按钮，默认工厂、销量观察天数、生产交期、安全库存天数常驻显示。
- 生产参数压缩为一行，保存后继续沿用现有补货/生产建议逻辑。
- 顶部增加耗材流转、生产/在途直达入口。
- 生产单列表继续全部展开，并增加“去执行”入口。
- 补齐已生产、已发货、已到货、部分入库等中文状态，避免流程推进后出现英文状态。
- 新建生产单与 SKU 行整体压缩，减少无效留白。

## 安全边界
- 不修改数据库结构。
- 不删除或重算真实业务数据。
- 不改变现有 API 请求路径与业务口径。
- 不改变 8000 单端口部署方式。
- 采购主工作台继续使用 `/purchase/workbench`。

## 后续方向
- 继续评估采购工作台中历史“全平台嵌入视图”的拆分，但在确认深链兼容前不强行移除。
- 到货入库与生产在途后续继续围绕“一行完成、状态直接看见”的原则优化。
