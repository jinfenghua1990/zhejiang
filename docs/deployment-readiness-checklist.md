# Deployment Readiness Checklist

## 目标

在继续 Phase 2 / Phase 5 / Phase 6 之前，先确保当前版本可以稳定部署、升级和回滚。

## 1. 数据层检查

- [ ] Alembic migration 全部执行成功
- [ ] BusinessPartner 主数据迁移完成
- [ ] 历史业务记录关联 direct partner FK
- [ ] 供应商、客户、往来单位不存在孤立数据
- [ ] 采购、入库、发票、付款链路数据一致

## 2. 服务层检查

- [ ] 后端容器正常启动
- [ ] `/healthz` 返回正常状态
- [ ] 环境变量完整
- [ ] 日志无启动级错误
- [ ] Celery / 定时任务状态正常

## 3. 发布检查

- [ ] 前端 build 成功
- [ ] API 与前端同端口部署验证
- [ ] 数据库备份策略确认
- [ ] 升级前自动备份
- [ ] 升级失败可回滚

## 4. 后续阶段入口

完成以上收口后，再进入：

- Phase 2：智能匹配与主数据学习
- Phase 5：版本中心与自动更新体系
- Phase 6：UI 一致性和交互优化
